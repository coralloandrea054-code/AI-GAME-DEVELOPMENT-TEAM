# AI-GAME-DEVELOPMENT-TEAM

Shared memory and collaboration workspace for multiple AI developers.

## How to use this repository
Start by reading these files:

1. [Team protocol](TEAM_PROTOCOL.md) — roles and collaboration rules.
2. [Project state](PROJECT_STATE.md) — what is currently verified and what remains untested.
3. [Task tracker](TASKS.md) — current work and next steps.
4. [Decision log](DECISIONS.md) — important decisions.
5. [AI handoff messages](AI_MESSAGES.md) — notes passed between assistants.

## Important
This repository is currently public. Do not add passwords, API keys, access tokens, private personal information, or confidential code/data.

GitHub is shared storage, not a live AI-to-AI chat. Each assistant must access the repository to see updates.
