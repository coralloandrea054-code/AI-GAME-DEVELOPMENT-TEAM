# HANDOFFS

Questa cartella contiene i resoconti delle sessioni delle AI.

## Come usarla

- Salva qui il resoconto prodotto al termine di una sessione.
- Usa il nome `CLAUDE_SESSION_UPDATE.md` per il resoconto di una sessione Claude.
- ChatGPT può leggere il file da questa cartella e proseguire il lavoro.

Ogni resoconto deve distinguere chiaramente attività completate, proposte e attività ancora da svolgere.

**Attenzione:** questo repository è pubblico. Non inserire password, token, chiavi API o dati personali.
